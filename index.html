Charge point management for EV charging

LeanCPMS: an open-source CPMS that is small, complete and debuggable.

Run public or housing-association chargers with load balancing, card payment by QR code and clear monthly reports.

What it does

Everything a site with a handful of chargers needs, and nothing it doesn't. You should be able to see what the system did, and why.

Load balancing

Per fuse group and per station phase. It reads the station meter, so other load on the same fuse is counted. If the balancer stops, chargers fall back to a safe default limit.

Drop-in charging

A QR code on each outlet leads to the price incl. VAT, card payment and a receipt. Drivers need no app and no account.

Your Stripe account is the seller

Payments go to the operator's own Stripe account, connected through Stripe Connect: you follow one link and finish Stripe's own onboarding. Drivers pay on Stripe's payment page with card, Apple Pay or Google Pay. Money never passes through the platform.

Monthly statements

Per site and per charge point: energy delivered, and money incl. and excl. VAT.

Open protocols

Chargers connect over OCPP 1.6J. OCPI 2.2.1 publishes your locations to services such as Nobil.

Configuration as code

Organization, price list and sites are versioned YAML documents. plan shows the change, apply makes it, as with infrastructure-as-code. See the three files.

API and CLI

A JSON API with OpenAPI docs, and the cpms command line with browser login. Install it from PyPI as leancpms-cli.

Operator portal

Overview, sessions, receipts and reports. Log in with a one-time code by e-mail; there are no passwords.

Open source

LeanCPMS is licensed under the AGPL-3.0-or-later. Anyone can run it themselves, read exactly what it does, and contribute.

The source code will be published on GitHub with the first release. Until then, contact us for early access.

The command-line client is already available: leancpms-cli on PyPI.

LeanCPMS Cloud

The hosted service from Forsslund Systems AB, for public charge point operators and housing associations.

  • We run it. We host and update the system, so you don't have to.
  • Your brand. Your own branding and your own driver domain, such as charge.yourcompany.com, or a page under leancpms.com.
  • Your Stripe account. Connect it with one link and Stripe's own onboarding; no API keys to handle. You are the seller on the receipt and payouts go straight to you. Our fee is a separate invoice.
  • No lock-in. Your configuration lives in your own repository as YAML. Manage it with the CLI, the API or AI agents. Because LeanCPMS is open source, you can always move to self-hosting.
  • Help getting started. We help you onboard your chargers and set up your price lists.
  • Housing associations. If you don't take card payments, you can get a monthly file for your accountant.
