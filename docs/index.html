LeanCPMS documentation¶

LeanCPMS is an open-source charge point management system (CPMS) for EV charging: small, complete, and debuggable. These pages are for the people who use an instance of it, such as LeanCPMS Cloud, and for developers who build on it. The product itself is described at leancpms.com.

LeanCPMS is pre-release. These pages describe the code as it is; where something is not built yet, they say so.

Guides¶

  • Users and access: people, organizations, roles and API keys, how to log in to the portal and with cpms login, and the common tasks of an organization's administrator.
  • The command line: installing cpms (uv tool install leancpms-cli), configuring it, managing an organization's YAML documents from a git repository, and using it from scripts and agents.

Driver API¶

  • The driver flow and the driver API: drop-in charging by QR code step by step, and /api/driver/v1/, the API for an organization's own driver front end.

Design¶

How the system is laid out, and why, will be published here: the architecture and the product requirements, written for readers outside the project. They are not public yet.

Source¶

The source code is licensed under AGPL-3.0. The repository is private until the system runs; the command line is published on PyPI as leancpms-cli.
